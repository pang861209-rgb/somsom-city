> 기준: "지금 이 상태로 바로 공개해도 사람들이 계속 하고 싶을까?"
> 기획(게임 재미·흐름)과 디자인(표현이 어설프지 않은가)을 나눠서 봅니다. 개발이 진행될 때마다 이 표를 고칩니다.

상태: ✅ 됨 · 🔧 이번에 고침 · ⏳ 남음 · ❓ 결정 필요

| 항목 | 상태 | 내용 |

## 5. 디자이너 점검 결과와 반영

1차 점검 총평: 타이틀·결과 카드·허브 타일은 형제 게임과 한 식구. **플레이 화면이 시제품 수준**이었음.

| 우선 | 항목 | 문제 | 반영 |
|---|---|---|---|
| P0 | 카메라·바깥 | 가장자리에서 화면 절반이 빈 단색 | ✅ 카메라 범위 제한, 바깥은 어두운 잔디+은행잎, 밧줄 울타리 |
| P0 | 무대 | 빨간 사각형 하나라 버그처럼 보임 | ✅ 바닥판·줄무늬 막·반원 장식·기둥·"솜재페" 현수막·반짝이는 전구 줄·양옆 은행나무 |
| P0 | 돗자리 색 | 북거씨가 잔디와 같은 색, 보늘 초록, 미개 회색 | ✅ 초록을 뺀 6색으로 재지정(미개 남색, 람다 벽돌, 보늘 머스터드, 북거씨 청록) |
| P0 | 돗자리 무늬 | 2칸 체크가 잔디 체크와 겹치고 짐 아이콘이 스티커처럼 흩어짐 | ✅ 피크닉 깅엄 무늬, 안쪽 바느질선, 아래 그림자. 짐 아이콘 삭제 |
| P0 | 끈 | 도로 차선·소시지처럼 보임 | ✅ 테두리·몸통·꼬임 3겹, 끌려오는 움직임, 시작점 매듭 |
| P0 | 캐릭터·내 표시 | 작고 묻힘, 노란 웅덩이 같은 표시 | ✅ 2.1칸으로 키움, 흰 스티커 외곽선, 주민 색 발그림자, 흰 고리+"나" 표시 |
| P0 | 끝 화면 | 마을 창고 알림이 시간·순위와 겹침 | ✅ 끝나면 위쪽 표시가 사라지고 안내 문구도 비움 |
| P0 | 글꼴 | 기기마다 굵기가 다른 기본 글꼴 섞임 | ✅ 숫자 Black Han Sans, 글 Gowun Dodum으로 통일 |
| P1 | 순위표 | 누가 누군지 연결 약함 | ✅ 색 원·내 줄 배경·1등 점, 순위 바뀔 때 미끄러지듯 이동 |
| P1 | 시간 | 막혀 보임 | ✅ "공연까지"로 줄이고 남은 시간 막대, 마지막 10초 깜빡임 |
| P1 | 아래 넓이·경고 | 둘째 줄이 안 읽힘 | ✅ 내 색 원, 도토리·별 아이콘, 넓이 늘면 숫자 튕김, 경고 "돗자리로 돌아가요!" |
| P1 | 꽈당 | 픽셀 파편 같음 | ✅ 끈 조각, 퍼지는 원, "꽈당!" 튕김 글자, 내가 넘어지면 화면 가장자리 붉게 |
| P1 | 공연 시작 | 밋밋함 | ✅ 큰 기울인 글자+그림자, 은행잎 색종이 |

2차 점검: "크게 좋아졌다. 이번 수정으로 새로 생긴 겹침 6개만 남음" → 모두 반영

| 우선 | 문제 | 반영 |
|---|---|---|

| P0 | 순위가 바뀌는 순간 이름·숫자가 겹쳐 깨져 보임 | ✅ 0.18초로 빠르게, 내려가는 줄은 흐리게, 올라가는 줄은 배경 깔고 위에, 상자 밖으로 안 샘 |
| P1 | 위로 갈 때 화살표와 "나" 표시가 겹침 | ✅ "나" 표시는 처음 3초와 다시 일어난 직후에만 |
| P1 | 안내 문구가 내 주민을 덮음 | ✅ 겹치면 아래쪽으로 비켜 감 (경고가 떠 있으면 그 위로) |

| P2 | 넘어졌을 때 내 표시 고리가 엇나감 | ✅ 누운 쪽으로 옮기고 가로로 늘림 |

## 6. 결정이 필요한 제안

**명당 규칙**: 무대에 가까운 앞자리일수록 한 칸의 가치가 큼(예: 맨 앞 줄 ×2). "자리 맡기"라는 이름과 솜재페 설정에 딱 맞고, Paper.io와 확실히 달라집니다. 대신 순위 기준이 "넓이"에서 "자리 점수"로 바뀌어 규칙이 한 줄 늘어납니다.
