# 「솜재페 자리 맡기」 출시 점검표

> 기준: "지금 이 상태로 바로 공개해도 사람들이 계속 하고 싶을까?"
> 기획(게임 재미·흐름)과 디자인(표현이 어설프지 않은가)을 나눠서 봅니다. 개발이 진행될 때마다 이 표를 고칩니다.

상태: ✅ 됨 · 🔧 이번에 고침 · ⏳ 남음 · ❓ 결정 필요

## 1. 처음 1분 (첫인상)

| 항목 | 상태 | 내용 |
|---|---|---|
| 시작하자마자 내 주민이 아무 데로나 걸어감 | 🔧 | 3·2·1 준비 시간. 그동안 밀어서 출발 방향을 정할 수 있음. 처음 방향은 잔디밭 가운데 쪽 |
| 규칙을 글로 읽게 함 | ✅ | 첫 두 판은 화면 안 안내 3단계(밖으로 나가 보세요 → 끈이 생겼어요 → 넓어졌어요) |
| 무엇을 하는 게임인지 한눈에 | ✅ | 타이틀에 솜재페 무대 그림 + "공연 전에 돗자리를 가장 넓게" |

## 2. 판 안의 재미

| 항목 | 상태 | 내용 |
|---|---|---|
| 욕심과 위험 사이의 긴장 | ✅ | 크게 돌수록 많이 얻지만 끈이 길어짐. 위험하면 끈이 빨갛게 깜빡이고 진동 |
| 주민이 '캐릭터'로 느껴지는가 | 🔧 | 상황별 말풍선(북거씨 "천천히, 천천히", 할머니 "아이구야", 보늘 "조금만 쉬자…"). 미개는 말 없는 설정이라 "…!" |
| 화면 밖 사건을 알 수 있는가 | 🔧 | 왼쪽 위 소식 줄: "람다가 북거씨 끈을 밟았어요", "람다가 크게 둘렀어요 +92칸" |
| 벽에 부딪히면 그냥 멈춤 | ⏳ | 지금은 멈춰 서서 다음 방향을 기다림. 실제 플레이 반응 보고 결정 |
| 사람 대 컴퓨터 난이도 | ⏳ | 컴퓨터끼리는 균형 확인(1등 8~25%). 사람이 하면 너무 쉬운지·어려운지는 실제 플레이로만 알 수 있음 |
