## 0. 왜 지금 업데이트하나

마지막 업데이트 뒤로 며칠이 지났습니다. 지금 있는 것 — 오늘의 통, 오늘의 규칙, 오늘의 숙제, 보상 컷 — 은 전부 **"매일 조금씩 다른 같은 판"**입니다. 한 주쯤 하면 판 자체가 익숙해집니다.

돌아온 사람이 "업데이트가 됐다"고 느끼려면 세 가지가 필요합니다.

| | 지금 | v3 |
|---|---|---|
| **새로 할 거리** | 판이 한 종류 | **오늘의 퍼즐** — 다른 모드 |
| **지금만 있는 것** | 없음 | **한가위 이벤트** — 9/23~10/5 한정 |
| **오래 모을 것** | 컷 295장 | **상자 꾸미기** — 업적으로 여는 통 무늬 |

그리고 이걸 **알려 줘야** 합니다. 새 기능은 발견되지 않으면 없는 것과 같습니다. 업데이트 뒤 처음 들어오면 **"새로워진 것"** 카드를 한 번 띄웁니다.

추석은 **2026년 9월 25일(금)**, 연휴는 24~27일입니다. 이벤트는 오늘 안에 나가야 의미가 있어서 이번 업데이트의 중심에 둡니다.

## 1. 한가위 이벤트 (9/23 ~ 10/5)

| | 내용 |
|---|---|
| **보름달 벽** | 플레이 화면 뒤 벽이 보름달이 뜬 창문과 송편 접시로 바뀝니다. 계절 벽 자리를 이벤트 기간에만 대신합니다 |
| **보름달 소원** | 보늘 둘이 만나 사라질 때 **점수 1.5배**, 그 자리에서 보름달이 떠오릅니다 |
| **한가위 컷 3장** | 여섯 친구의 추석 — 평상에서 송편 빚기 · 옥상에서 보름달 소원 · 할머니 댁 명절 상. 이벤트 기간에 **2000점 이상인 판마다 한 장**씩 열립니다(평소 컷 기준 5000점보다 낮게) |
| **이벤트 업적** | 「한가위」 — 한가위 컷 세 장을 다 모으면 |
| **타이틀 띠** | "한가위 보름달 · ~10/5" |

이벤트 컷은 앨범에 따로 한 줄로 묶어, 끝난 뒤에도 "그해 추석에 모은 것"으로 남습니다. 끝난 뒤에는 새로 열리지 않습니다.

**신규 작화**: 한가위 컷 3장 + 보름달 벽 1장. 전부 멀티샷(컷은 pro 6샷씩, 벽은 flash 4샷).

## 2. 오늘의 퍼즐 — 새 모드

### 한 줄

**이미 반쯤 찬 통에, 전부 보이는 조각 12개로, 최대한 높이.**

### 왜 이 모드인가

지금 판은 60~80개를 쏟는 **긴 호흡**입니다. 퍼즐은 12개로 끝나는 **짧은 생각**입니다. 1분이면 끝나고, 운이 없습니다.

- **다음에 뭐가 올지 전부 보입니다.** 12개 줄이 화면 위에 다 깔려 있습니다. 그다음 미리 보기의 극단입니다
- **통이 이미 차 있습니다.** 빈 통에서 시작하면 그냥 짧은 판이지만, 반쯤 찬 통은 "이 상황에서 어떻게 할래"가 됩니다
- **모두 같은 문제입니다.** 날짜 씨앗으로 시작 배치와 12개 줄이 정해집니다
- **별 세 개**: ★ 끼토를 만들었다 · ★★ 보늘을 만들었다 · ★★★ 보늘 소멸 또는 완벽 정리

점수와 별개로 별을 두는 이유는, 점수 눈금은 퍼즐마다 다르지만 **"보늘까지 갔나"는 누구나 알아듣기 때문**입니다.

### 규칙

| | |
|---|---|
| 시작 통 | 날짜 씨앗으로 7~9개를 떨어뜨려 가라앉힌 상태. 같은 단계끼리 닿아 있으면 한 단계 올려서 다시 배치 |
| 조각 | 12개 고정, 전부 보임. 바꾸기 1번, 흔들기 없음 |
| 과열·연쇄 | 그대로 |
| 끝 | 12개를 다 놓고 잠잠해지면, 또는 넘치면 |
| 순위 | 오늘의 퍼즐 순위판 (새 컬렉션 `merge_puzzle`) |

### Firestore

새 컬렉션이라 규칙 추가가 필요합니다. 규칙 전에도 퍼즐은 되고, 순위판만 "내 기록"으로 대신 보여 줍니다.

## 3. 상자 꾸미기

업적으로 여는 통 무늬 네 가지. 도토리로 사는 게 아닙니다 — v2에서 "도토리는 칭호용 공용 재화로만" 두기로 한 결정을 지킵니다.

| 무늬 | 여는 조건 |
|---|---|
| 기본 나무 | 처음부터 |
| 조약돌 상자 | 보늘 10번 만들기 (누적) |
| 호두나무 상자 | 과열 10번 (누적) |
| 금테 상자 | 완벽 정리 1번 |

타이틀의 「상자」에서 고릅니다. 잠긴 건 조건을 적어 둡니다. **순전히 모양만 바뀝니다.**

---

## 4. 새로워진 것

업데이트 뒤 처음 들어오면 카드 한 장. 네 줄 이내. 닫으면 다시 안 뜹니다(버전 키 저장).

---

## 5. 안 하는 것

- **같이 하기(한 폰 번갈아)** — 이번에도 다음으로. 이름 입력 흐름이 이번 업데이트 전체만큼 큽니다
- **도토리 상점** — 위의 이유
- **이벤트 전용 캐릭터·조각** — 캐논은 여섯

## 6. 검증 기준

| | 통과 조건 |
|---|---|
| 이벤트 | 기간 안/밖 날짜를 강제로 넣어 벽·배율·컷·띠가 켜지고 꺼짐 |
| 퍼즐 | 같은 날 새로고침해도 같은 시작 통·같은 12개. 시작 통에 같은 단계가 닿아 있지 않음. 별 판정 |
| 상자 | 조건 달성 전 잠김, 달성 뒤 선택 가능, 선택 유지 |
| 새로워진 것 | 첫 방문 1회만 |
| 회귀 | 흐름 QA · 허브 QA · 봇 이탈 0 · JS 오류 0 |


## 덧붙임 — 솜솜시티 테마곡 (마을 전체)

- 허브와 게임 네 개(낙엽피하기·달리기·짝맞추기·솜솜 합체)에서 같은 노래가 반복 재생됩니다. 공용 파일 `assets/bgm.js` 하나를 각 페이지가 불러 씁니다.
- 페이지를 옮기면 멈춘 자리부터 이어서 틉니다. 페이지가 바뀌는 순간 1초 안팎 끊기는 것은 페이지가 따로라서 피할 수 없습니다.
- 휴대폰은 페이지마다 첫 탭 전에는 소리를 막습니다. 게임은 어차피 누르면서 시작하니 첫 탭에 노래가 이어집니다.
- 게임마다 있던 삐삐 소리 배경음(합성음)은 테마곡이 대신하므로 끕니다. 효과음은 그대로입니다.
- 음량: 허브 0.5, 게임 안 0.3(효과음이 묻히지 않게).
- 끄기: 화면 왼쪽 위 "← 홈" 옆의 ♪ 버튼. 끄면 모든 페이지에서 꺼진 채로 유지됩니다(`somsom_bgm_off`). 게임 중에는 일시정지 버튼과 자리가 겹쳐 ♪를 숨깁니다. 게임 중에는 각 게임의 소리 버튼(🔊)을 누르면 노래도 같이 멈춥니다.
- 방범대는 다른 저장소(somsom-city-game)에 있어 이번에는 넣지 않았습니다.
