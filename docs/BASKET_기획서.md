# 솜솜시티 게임 5호 — 「할머니네 가을 바구니」 기획서 v1.0

> 한 줄 정의: 라칠친 할머니의 바구니에 가을 열매를 떨어뜨려, **같은 열매끼리 부딪히면 한 단계 큰 열매로 합쳐지는** 물리 합치기 퍼즐.
> 은행 한 알에서 시작해 당근빌라 명물 **'당근 케이크'**까지 키우는 것이 목표입니다.

---

## 1. 왜 이 장르인가

| 기준 | 판단 |
|---|---|
| 중독성 | '수박게임(스이카)' 계열은 규칙이 한 줄인데 "한 판만 더"가 강하게 걸리는 대표 장르입니다. 판이 끝날 때마다 "조금만 더 잘 놓았으면" 하는 아쉬움이 남도록 설계되어 있습니다. |
| 기존 4종과 겹치지 않음 | 낙엽피하기(반사신경) · 달리기(타이밍) · 짝맞추기(기억) · 방범대(전략)와 다른 **공간 퍼즐 + 물리** 재미입니다. |
| 세계관 연결 | 라칠친 할머니가 은행을 줍는 설정(방범대의 '은행 회수')을 그대로 이어받습니다. 가을 골목 · 도토리 경제와도 맞습니다. |
| 폰 조작 | 손가락 하나로 좌우 이동 → 떼면 떨어짐. 설명이 필요 없습니다. |
| 한 판 길이 | 3~8분. 쉬는 시간에 한 판. |

## 2. 핵심 규칙

1. 위에서 친구가 열매를 들고 있습니다. 화면을 끌어서 위치를 정하고, 손을 떼면 떨어집니다.
2. 같은 열매 두 개가 닿으면 **한 단계 위 열매**로 합쳐지고 점수를 얻습니다.
3. 열매가 **빨간 점선(넘침선)** 위에 2.5초 이상 머무르면 바구니가 넘쳐 게임이 끝납니다. (넘침선을 넘으면 경고 → 카운트다운이 보입니다.)
4. 다음에 떨어질 열매가 미리 보입니다(NEXT).

### 2.1 열매 사다리 (11단계)

| 단계 | 열매 | 반지름(px) | 합칠 때 점수 | 비고 |
|---|---|---|---|---|
| 1 | 은행 | 15 | 1 | 떨어지는 열매 |
| 2 | 도토리 | 20 | 3 | 떨어지는 열매 |
| 3 | 알밤 | 26 | 6 | 떨어지는 열매 |
| 4 | 솔방울 | 32 | 10 | 떨어지는 열매 |
| 5 | 귤 | 39 | 15 | 떨어지는 열매(드물게) |
| 6 | 감 | 47 | 21 | |
| 7 | 사과 | 55 | 28 | |
| 8 | 배 | 64 | 36 | |
| 9 | 석류 | 73 | 45 | |
| 10 | 호박 | 84 | 55 | |
| 11 | 당근 케이크 | 97 | 66 (+ 케이크 보너스 500) | 최종 단계. 케이크 둘이 만나면 '케이크 파티'로 사라지며 대박 점수 |

- 점수 = 단계별 기본 점수 × **연쇄 배수**.
- 떨어지는 열매는 1~5단계에서만 나옵니다(1~3이 대부분). 초반은 쉽고, 바구니가 차면서 자연스럽게 어려워집니다.

## 3. 중독 장치 — "한 판만 더"를 만드는 7가지

| # | 장치 | 내용 | 노리는 감정 |
|---|---|---|---|
| 1 | **연쇄 콤보** | 한 번 떨어뜨려 합치기가 0.75초 간격으로 이어지면 연쇄 +1, 점수 배수 ×1.0 → ×1.5 → ×2 … (최대 ×4). 화면에 "3연쇄!" 표시·효과음 음정 상승 | 우연한 연쇄의 짜릿함 |
| 2 | **처음 만든 열매 발견** | 판 중 처음 보는 단계를 만들면 슬로모션 + "새 열매 발견!" 카드 + 친구 한마디. 도감에 영구 등록 | 수집욕, 다음 단계 궁금증 |
| 3 | **아슬아슬 경고** | 넘침선 근처에서 바구니 테두리가 빨갛게 숨 쉬고 심장박동 효과음 | 긴장 → 탈출 시 해방감 |
| 4 | **친구 스킬** | 합칠 때마다 스킬 게이지가 차고, 가득 차면 친구 고유 스킬 1회 사용 | 위기 탈출 카드, 캐릭터 애정 |
| 5 | **도토리 보상 · 친구 해금** | 판 점수에 비례해 도토리 적립 → 도토리로 새 친구 해금 | 장기 목표 |
| 6 | **최고 기록 · 거의 다 왔어요** | 결과 화면에 "최고 기록까지 N점", 가장 큰 열매 표시 | 아쉬움 → 재도전 |
| 7 | **한 번 더 기회** | 판당 1회, 도토리 30개로 넘친 윗부분 열매를 치우고 이어하기 | 매몰 비용 → 계속 플레이 |

추가로 매일 바뀌는 **오늘의 목표 3개**(예: "사과 만들기", "4연쇄", "2,000점")를 두어 매일 들어올 이유를 만듭니다.

## 4. 친구 6명 — 떨어뜨리는 캐릭터 + 스킬

친구마다 **스킬 1개**와 **패시브 1개**가 있습니다. 판을 시작할 때 한 명을 고릅니다.

| 친구 | 해금 | 스킬 (게이지 가득) | 패시브 | 역할 |
|---|---|---|---|---|
| 라칠친 할머니 | 기본 | **은행 줍기** — 바구니 속 은행·도토리를 모두 주워 담음 | 주운 열매 하나당 도토리 +1 | 공간 확보 |
| 끼토 | 기본 | **귀 흔들기** — 바구니를 흔들고 1.5초 동안 가까운 같은 열매끼리 끌어당김 | 스킬 게이지 20% 빨리 참 | 합치기 유도 |
| 람다 | 도토리 120 | **황금 도토리 2개** — 닿은 열매의 짝을 바구니 어디서든 끌어와 합침(짝이 없으면 한 단계 키움) | 판 끝 도토리 +25% | 떨어진 짝 연결·경제 |
| 미개 | 도토리 220 | **뽈뽈 운반** — 탭한 열매 하나를 들고 나감 | 연쇄 유지 시간 +0.35초 | 방해물 제거 |
| 보늘 | 도토리 350 | **뒹굴 청소** — 맨 위 열매 3개를 굴려서 치우고 2.5초 넘침 정지 | 넘침 허용 +1초 | 위기 탈출 |
| 북거씨 | 도토리 500 | **숙성 향수** — 탭한 열매와 같은 열매를 전부 둘씩 짝지어 합침 | 다음 열매 2개 미리보기 | 한 방 정리 |

- 스킬 게이지: 합칠 때 (1.3 + 단계×0.5) 충전, **쓸 때마다 다음 충전이 25%씩 느려짐** → 한 판 3~5회 (자동 플레이 측정)
- 친구 레벨(Lv.1~5): 도토리 100/200/350/500으로 레벨 업, 레벨당 스킬 충전 +8% — 해금이 끝난 뒤의 도토리 사용처
- 스킬 효과 측정값은 `docs/basket-review.md` 참고
- 친구 해금 가격은 한 판 평균 도토리(약 70~110개, 목표·출석 포함) 기준, 1~3판마다 한 명씩 열리게 잡았습니다.

## 5. 화면 구성 (세로 420 × 760 논리 해상도, 폰 화면에 맞춰 확대·축소)

```
┌──────────────────────────────┐
│ 점수 1,240   최고 3,820   ⏸  │  ← 상단 HUD
│ [친구] 스킬게이지 ▓▓▓░  NEXT ● │
│         (친구가 열매 들고 있음) │
│ - - - - - 넘침선 - - - - - - - │
│ |                          | │
│ |        바구니 속          | │  ← 물리 영역 (폭 360)
│ |      열매들이 쌓임         | │
│ |__________________________| │
│   오늘의 목표 1/3 · 🌰 +12     │
└──────────────────────────────┘
```

- 배경: 은행나무 골목(기존 bg_alley) 위에 나무 바구니.
- 화면 흐름: 타이틀 → 친구 고르기 → 플레이 → 결과(점수·최고·가장 큰 열매·도토리·오늘의 목표) → 다시하기(한 번 탭).

## 6. 물리 설계 (직접 구현, 외부 라이브러리 없음)

- 원(열매) 사이 충돌만 필요하므로 **위치 기반(Verlet) 물리**를 씁니다. 한 프레임을 8번 잘게 나눠 계산해 열매가 파묻히거나 튀지 않게 합니다.
- 굴러가는 느낌: 좌우 이동량만큼 회전값을 더해 열매가 실제로 굴러가 보이게 합니다.
- 합치기: 두 열매 중간 지점에 새 열매가 작게 생겨 0.15초 동안 커지며 주변을 자연스럽게 밀어냅니다.
- 넘침 판정: 떨어진 지 1초가 안 된 열매는 판정에서 뺍니다(막 떨어뜨린 열매로 억울하게 지는 것 방지).

## 7. 솜솜시티 허브 연동

기존 게임들과 같은 저장 키를 씁니다.
- `somsom_stats.coins` — 판 도토리의 일부를 마을 공용 도토리로 적립(허브 칭호 진행에 반영)
- `somsom_stats.chars` — 사용한 친구 기록(허브 대표 캐릭터 반영)
- `somsom_ach` — 업적 기록(`basket_*`)
- 마을 창고(`village.js`의 `SV.add`) — 있으면 적립, 없으면 조용히 건너뜀
- 게임 자체 저장: `somsom_basket` (최고 점수, 도감, 해금 친구, 도토리, 오늘의 목표 진행)

허브 첫 화면에 5번째 카드를 붙이는 작업은 허브 저장소(somsom-city) 쪽 수정이 필요해 이번 범위에서 뺐습니다.

- 배수: 2연쇄 ×1.5 … 최대 ×4 → 2연쇄 ×2, 3연쇄 ×3 … 8연쇄 이상 ×8 (평균 점수 2,824 → 3,778, 콤보 비중 약 1/2)
- 연출: 바구니 가운데 큰 'N연쇄 · 점수 ×N' + 다음 합치기까지 남은 시간 막대, 단계별 색(주황→빨강→분홍→보라→파랑), 3연쇄부터 흔들림·진동·파티클, 4연쇄부터 화면 번쩍임, 떠오르는 점수에 ×배수 표시
- 연쇄가 끊기면 'N연쇄 보너스 +점수'를 크게, 3연쇄 이상은 팡파르와 친구별 외침, 5연쇄 이상은 폭죽
