# 「솜솜 합체」 v2 기획서

작성 2026-09-13 밤 · v1(PR #16·#17·#18) 머지 뒤

---

## 0. v1이 남긴 것

v1은 **"판이 그 자리에서 완결되고, 랭킹은 덤"**이라는 원칙으로 만들었습니다. 그 원칙은 지킵니다. 다만 실기와 QA에서 v1이 못 채운 자리가 보입니다.

| v1에 있는 것 | 비어 있는 자리 |
|---|---|
| 오늘의 통 — 하루 동안 모두 같은 조각 순서 | **그래서 오늘 누가 몇 점인지 게임 안에서 볼 곳이 없습니다.** 조용히 올라가기만 하고 돌아오는 게 없습니다 |
| 매 판 다른 물리 | 그런데 **매일은 같은 게임**입니다. "오늘은 무슨 날?"이 없습니다 |
| 결과 화면 뒤에 남는 통 | "내 통 봐"를 **가족 채팅방에 보낼 방법**이 없습니다 |
| 합체 링·흔들림·표정 | 보늘 소멸이 이 게임의 승부처인데 **연출이 합체와 같습니다** |
| 상점 벽 배경 한 장 | 계절이 안 바뀝니다. 솜솜시티는 사계가 있는 동네입니다 |

v2는 **새 규칙을 얹지 않습니다.** 손이 하는 일(떨어뜨린다·합친다·바꿔 둔다)은 v1 그대로입니다. 골목 원정대에서 배운 것 — 시스템을 얹기 전에 동사부터 — 은 이미 v1에서 치렀으니, v2는 **판 바깥을 채웁니다.** 판이 끝난 뒤 돌아오는 것, 내일 다시 올 이유, 가족에게 보여줄 방법.

## 1. v2의 한 줄

> **같은 통을 두고 가족이 하루씩 겨루는 게임.** 판은 v1 그대로, 그 판을 둘러싼 하루를 만듭니다.

## 2. 기능

우선순위 순입니다. P1은 이번에 만들고, P2는 시간이 되면, P3는 다음 판입니다.

### P1-A. 오늘의 순위판

- 결과 화면과 타이틀에 **「오늘의 순위」** 버튼. 누르면 오늘 날짜(`d`)의 `merge_scores`를 읽어 닉네임별 최고점을 순서대로 보여줍니다
- 내 이름은 강조. 아직 아무도 없으면 "첫 번째가 되어 보세요"
- 어제 이전은 안 보여줍니다. **오늘 하루가 단위**입니다. 주간 합산은 허브 🏆에 이미 있습니다
- Firestore 인덱스가 따로 필요 없도록 `d == 오늘` 조건 하나로만 읽고 정렬은 화면에서 합니다(같음 조건 하나는 자동 인덱스로 됩니다. 정렬을 서버에 시키면 복합 인덱스를 콘솔에서 또 만들어야 합니다)
- 실패하면 "지금은 못 불러왔어요" 한 줄. 게임엔 영향 없음

**왜 먼저인가**: 오늘의 통을 만들어 놓고 결과를 안 보여주면 그 장치가 없는 것과 같습니다. v1의 미완성분입니다.

### P1-B. 오늘의 규칙

날짜를 씨앗으로 **하루에 규칙 하나**를 뽑습니다. 모두 같은 규칙, 같은 순서라 순위판은 공정합니다.

| 규칙 | 무엇이 다른가 | 한 줄 안내 |
|---|---|---|
| 보통 날 | 없음 | — |
| 미개가 많은 날 | 미개 55% · 북거씨 30% · 할머니 15% | 작은 친구가 자주 옵니다 |
| 할머니가 많은 날 | 미개 15% · 북거씨 30% · 할머니 55% | 큰 친구가 자주 와서 통이 빨리 찹니다 |
| 바꾸기가 넉넉한 날 | 바꾸기 3 → 6 | 바꿔 두기를 여섯 번 |
| 보늘이 후한 날 | 소멸 보너스 5 → 10 조각 | 보늘 둘이 돌아가며 열 개를 두고 갑니다 |
| 통이 얕은 날 | 통 높이 82% | 넘치기 쉽습니다 |

- 보통 날은 나머지보다 뽑힐 확률을 두 배로 둡니다. 매일이 특별하면 특별한 게 없습니다
- 타이틀 안내 줄과 HUD 왼쪽 위에 규칙 이름을 씁니다. 읽을 게 한 줄을 넘지 않습니다
- 규칙은 **숫자만 바꿉니다.** 새 조작, 새 조각, 새 캐릭터 없음

**왜**: 내일 다시 열 이유입니다. 콘텐츠를 사람이 만들 필요가 없는 무한 장치이고, 아이도 한 줄로 이해합니다.

### P1-C. 자랑하기 (결과 이미지 공유)

- 결과 카드에 **「자랑하기」** 버튼. 끝난 통 모습 + 점수 + 날짜 + 닉네임을 한 장(1080×1350)으로 그려서 휴대폰 공유 시트로 넘깁니다(`navigator.share`, 파일 공유)
- 공유 시트가 없는 브라우저에서는 이미지를 새 탭으로 엽니다(길게 눌러 저장)
- 이미지에 "솜솜시티 · 솜솜 합체"와 주소를 작게 넣습니다

**왜**: 가족 게임은 채팅방에서 삽니다. "내 통 봐"가 그대로 카카오톡에 올라가야 합니다.

### P1-D. 보늘 소멸 연출 · 점수 뜨기

- 보늘 둘이 만나면 그 자리에서 **둘이 천천히 위로 떠올라 사라집니다**(1초). 지금은 합체와 같은 링뿐입니다
- 합체할 때 **"+45" 같은 점수가 그 자리에서 떠오릅니다.** 연쇄면 "+45 ×3"
- 조각이 다 떨어지고 결과 카드가 올라올 때 0.4초 슬라이드

**왜**: 승부처가 승부처처럼 보여야 합니다. 점수가 어디서 나오는지 보이면 "높이 올려야 한다"를 설명 없이 배웁니다.

### P2-E. 계절 벽

- 상점 벽 배경을 **봄·여름·가을·겨울 네 장**으로. 선반 위 소품만 바뀝니다(벚꽃 가지 · 수국 · 은행잎 · 귤과 눈사람). 벽은 여전히 조용해야 합니다
- 월로 고릅니다. 3~5 봄, 6~8 여름, 9~11 가을, 12~2 겨울
- 멀티샷 4장씩. 못 불러오면 v1 벽으로

### P2-F. 같이 하기 (한 휴대폰으로 번갈아)

- 타이틀에서 **「같이 하기」** → 이름 2~4개 → 한 사람씩 같은 오늘의 통을 한 판 → 끝나면 비교표
- 네트워크 없이 됩니다. 아이와 부모가 한 폰으로 겨루는 상황이 실제로 제일 흔합니다
- 각자의 점수는 평소처럼 조용히 올라갑니다

**이번에 안 만들 수도 있습니다.** 이름 입력 화면과 흐름이 P1 넷을 합친 것만큼 큽니다. 기획만 남깁니다.

### P3 — 다음 판으로

- 주간 도전(일요일마다 특별 규칙 + 별도 순위)
- 결과 화면에서 바로 "친구에게 도전장" 링크(오늘의 통 + 내 점수가 박힌 주소)
- 솜솜시티 허브 카드에 "오늘의 규칙" 노출

## 2.5 만든 것 (2026-09-13 밤)

| 기능 | 상태 | 확인 |
|---|---|---|
| P1-A 오늘의 순위판 | 완료 | 가짜 응답으로 정렬·내 이름 강조·빈 상태·실패 상태 확인 |
| P1-B 오늘의 규칙 | 완료 | 여섯 규칙 각각 실제 수치에 반영(투하 비율 54/30/16·14/30/56, 바꾸기 6, 보너스 10, 통 높이 571→468) |
| P1-C 자랑하기 | 완료 | 1080×1350 이미지 생성, 공유 API 없을 때 시트 폴백. 공유 시트 자체는 실기에서 확인 필요 |
| P1-D 연출 | 완료 | 점수 글자·소멸 유령·카드 슬라이드. 프레임 0.4ms |
| P2-E 계절 벽 | 완료 | 16샷 중 4장 선별. 월로 선택, 실패 시 v1 벽 |
| P2-F 같이 하기 | **다음 판** | 기획만 |

## 3. 안 하는 것

- **시간 제한** — v1에서 뺀 이유 그대로. 반사신경 게임이 됩니다
- **새 단계·새 캐릭터** — 캐논은 여섯입니다
- **아무 단계와 합쳐지는 특수 조각** — 운이 커지고 규칙이 흐려집니다
- **인앱 재화로 사는 것** — 도토리는 칭호용 공용 재화로만 둡니다

## 4. 검증 기준

| 기능 | 통과 조건 |
|---|---|
| 순위판 | 오늘 기록이 있으면 닉네임별 최고점이 내림차순으로, 내 이름 강조. 없으면 안내 한 줄. 읽기 실패 시 오류 없이 안내 한 줄 |
| 오늘의 규칙 | 같은 날 새로고침해도 같은 규칙·같은 순서. 여섯 규칙 각각이 실제 수치에 반영(자동 플레이로 확인) |
| 자랑하기 | 1080×1350 이미지가 만들어지고 점수·날짜·닉네임이 들어 있음(헤드리스에서 픽셀 검사). 공유 API 없을 때 새 탭 |
| 연출 | JS 오류 0, 60fps 유지(조각 20개에서 프레임 시간 < 8ms) |
| 회귀 | v1 흐름 QA·허브 QA 전부 통과 |

## 5. 리스크

**하나. 순위판이 비어 보일 수 있습니다.** 가족 넷이면 하루 네 줄입니다. 그래서 "첫 번째가 되어 보세요"를 넣고, 빈 순위판을 부끄러운 화면이 아니라 초대장처럼 씁니다.

**둘. 오늘의 규칙이 어떤 날은 재미없을 수 있습니다.** 그래서 보통 날 확률을 두 배로 두고, 규칙은 여섯 개뿐이며 전부 숫자 조정입니다. 재미없는 규칙은 표에서 지우면 그날부터 안 나옵니다.

**셋. 공유는 기기마다 다릅니다.** iOS Safari·안드로이드 크롬은 파일 공유가 되고, PC 브라우저는 안 됩니다. 안 되면 새 탭 열기로 물러납니다. 제 환경에서는 공유 시트를 못 띄우므로 이미지 생성까지만 검증합니다.
