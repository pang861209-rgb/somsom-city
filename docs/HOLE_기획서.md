# 신작 후보 「구멍으로 쏙」 시험판(M0)

작성 2026-10-13 · 자리 맡기 플레이 후 "괜찮지만 중독성이 약하다" → 다른 안 중 1번 선택

## 한 줄
솜재페가 끝난 잔디밭. 내 구멍을 움직여 나보다 작은 물건을 삼키면 구멍이 커집니다. 1분 뒤 가장 많이 치운 주민이 1등입니다.
원작 장르: Hole.io, All in Hole.

## 왜 이 안인가
| 자리 맡기에서 약했던 점 | 이 안에서 |
|---|---|
| 한 판 2분, 넘어지면 손해 본 채 계속 | 한 판 1분, 결과 화면에서 바로 "한 판 더" |
| 커지는 맛이 몇 초에 한 번 | 물건 하나 삼킬 때마다 소리·점수·크기가 바로 바뀜 |
| 원작부터 혼자 하면 금방 질리는 장르 | 매출 상위권 퍼즐(All in Hole)과 같은 손맛 |

## 규칙
1. 화면 어디든 누르고 밀면 그쪽으로 움직입니다(손가락 아래 조이스틱).
2. 내 구멍보다 작은 물건은 가까이 가면 미끄러져 쏙 빠집니다. 큰 물건은 가장자리에서 흔들리기만 합니다.
3. 삼킨 만큼 구멍이 커집니다. 은행잎 → 종이컵 → 도시락 → 접이의자 → 돗자리 → 벤치 → 푸드트럭 → 은행나무 → 무대.
4. 나보다 1.25배 이상 큰 구멍은 나를 삼킬 수 있습니다. 삼켜지면 1.5초 뒤 70% 크기로 다시 나오고 2초 동안 안전합니다.
5. 점수 = 삼킨 물건 크기(은행잎 1점 ~ 무대 269점). 1분 뒤 점수 순위.

## 중독 장치 (시험판에 들어간 것)
- 연속으로 삼키면 소리가 점점 높아지고 5개마다 "N연속 쏙!"
- 아래 "다음: 벤치" 막대 — 다음 크기까지 얼마나 남았는지. 넘으면 "커졌다! 이제 벤치도 쏙"
- 큰 물건(벤치 이상)을 삼키면 화면 흔들림·진동
- 내 최고 기록

## 수치 (`hole/core.js` DEFAULTS)
| 항목 | 값 |
|---|---|
| 잔디밭 | 1400 × 1400 |
| 처음 구멍 크기 | 12 (은행잎·종이컵·도시락만) |
| 움직이는 속도 | 80 + 크기×1.5 |
| 커지는 비율 | 삼킨 넓이의 22% |
| 물건 수 | 약 640개 (은행잎 300, 종이컵 160, 도시락 100, 의자 32, 돗자리 22, 벤치 12, 푸드트럭 6, 은행나무 8, 무대 1) |

자동 대전(`hole/sim.js`, 컴퓨터끼리 60판)
- 1등 비율 13~20%로 고름
- 가장 큰 주민이 의자 1초, 벤치 9초, 푸드트럭 19초, 은행나무 32초, 무대 50초 무렵에 도달 (무대까지 가는 판은 약 45%)
- 판 끝에 남는 물건 약 24개

## 시험판에서 확인할 것
1. 1분이 짧은지 긴지
2. 컴퓨터에게 삼켜지는 게 억울한지, 긴장감인지
3. "한 판 더"를 누르게 되는지

## 다음 단계 (재미가 확인되면)
주민 그림 구멍 테두리, 물건 그림, 떨어지는 연출 다듬기, 허브 연결(미션·업적·순위).
