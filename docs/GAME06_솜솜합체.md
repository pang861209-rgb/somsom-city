작성 2026-09-13 · 성공 기준: **가족이 반복해서 노는 것**

장르 조사(`docs/CASUAL_GENRE_SURVEY.md`)에서 드롭 앤 머지를 고른 뒤의 본 기획서입니다. 방범대 설계 문서의 구성과 규격을 승계합니다.

## 1. 서비스 개요

### 1.1 한 줄

골목에 친구를 떨어뜨립니다. 같은 친구 둘이 만나면 한 뼘 더 큰 친구가 됩니다. 넘치면 끝납니다.

### 1.2 이번엔 왜 이 형태인가

두 번 접었습니다.

| 안 | 왜 접었나 |
|---|---|
| 골목 원정대 (피한다) | **동사를 안 바꿔서** 낙엽피하기와 구분이 안 됨 |
| 틀린그림찾기 (찾는다) | **콘텐츠가 고갈되고 외워짐** |

그래서 기준이 여섯 개가 됐습니다.

| 기준 | 이 설계에서 |
|---|---|
| 한 판 5분 이내 | 2~4분 |
| 행동에서 결과까지 3초 이내 | 떨어뜨리면 즉시 |
| 판이 그 자리에서 완결 | 넘치면 끝. 점수와 "제일 큰 친구"가 남음 |
| **새 동사** | **떨어뜨린다 · 합친다.** 피한다/뛴다/기억한다/배치한다 어디와도 안 겹침 |
| **절차적으로 무한** | 물리 + 랜덤 순서. **사람이 콘텐츠를 만들 필요가 없음** |
| 아이와 어른 대등 | 반사신경이 아니라 자리 잡기. 시간 압박 없음 |

### 1.3 캐논이 곧 게임 규칙입니다

비주얼 바이블에 확정된 캐릭터 키 순서가 그대로 합체 사다리입니다.

```
미개 37  →  북거씨 43  →  라칠친 52  →  람다 61  →  끼토 91  →  보늘 100
```

억지로 갖다 붙인 게 아닙니다. **캐릭터를 여섯만 쓴다는 제약이 머지 게임에 딱 맞는 단계 수**입니다.

## 2. 합체 사다리

| 단계 | 캐릭터 | 캐논 신장 | 게임 반지름 | 합체 점수 | 떨어뜨리기 |
|---|---|---|---|---|---|
| 0 | 미개 | 30cm | 15 | 1 | 가능 |
| 1 | 북거씨 | 저상 | 20 | 3 | 가능 |
| 2 | 라칠친 할머니 | 116cm | 26 | 6 | 가능 |
| 3 | 람다 | 118cm | 33 | 12 | 합체로만 |
| 4 | 끼토 | 125cm | 41 | 24 | 합체로만 |
| 5 | 보늘 | 145cm | 52 | 50 | 합체로만 |

**반지름은 캐논 수치가 아니라 게임용으로 고르게 벌린 값입니다.** 캐논을 그대로 쓰면 끼토 91 → 보늘 100 구간이 거의 안 커져서 합체가 눈에 안 보입니다. **순서만 캐논을 따릅니다.**

떨어지는 건 아래 세 단계(미개·북거씨·할머니)뿐입니다. 위 세 단계는 합쳐야만 나옵니다.

### 2.1 보늘 + 보늘 = 소멸

최종 단계가 쌓이기만 하면 통이 막혀 판이 죽습니다. **보늘 둘이 만나면 둘 다 사라지고 큰 점수를 줍니다.** 자리도 비고 보상도 큽니다. 이게 이 장르의 표준 해법입니다.

## 3. 화면 스펙 (420×680)

```
┌────────────────────────────┐  0
│ HUD 58px                   │   2303        다음 ●
│  최고 1820                 │
├────────────────────────────┤  58
│   떨어뜨리는 공간 74px      │        ●  ← 손가락 따라 좌우
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤ 132  넘침선 (점선)
│                            │
│   통                        │
│                            │
│         ●●                 │
│      ●●●●●●                │
└────────────────────────────┘
```

- **넘침선 위로 1.15초 이상 정지해 있으면 종료.** 방금 떨어뜨린 것(1초 미만)과 아직 움직이는 것(|vy|>42)은 봐줍니다. 억울한 죽음을 막기 위해서입니다
- 통 좌우 여백은 화면 폭의 4.5%
- 낙하 가이드선을 점선으로 그려 어디에 떨어질지 보여줍니다

### 3.1 상태 머신

```
BOOT → TITLE → PLAY ⇄ PAUSE → OVER → (다시 | 타이틀)
```

단순합니다. 스테이지 선택도 로비도 없습니다. **판이 전부입니다.**

### 3.2 조작

- 화면을 좌우로 문지르면 손에 든 친구가 따라옵니다
- **손을 떼면 떨어집니다**
- 키보드: 좌우 화살표, 스페이스/아래 화살표로 투하
- 투하 후 0.36초 잠금 (연타 방지)

## 4. 물리

외부 라이브러리 없이 직접 구현합니다. 원형 강체만 있으면 되기 때문입니다.

| 상수 | 값 | 이유 |
|---|---|---|
| 중력 | 1500 px/s² | |
| 반발 | 0.12 | 낮게. 통통 튀면 정신없습니다 |
| 마찰 | 0.86 | 바닥 접촉 시 접선 감쇠 |
| 공기저항 | 0.999 | |
| 보정 반복 | 8회 | 쌓임 안정성. 적으면 파고듭니다 |
| 고정 스텝 | 1/120초 | 프레임과 분리. 느린 기기에서도 같은 물리 |

- 적분은 semi-implicit Euler
- 충돌은 **위치 보정 + 법선 속도 감쇠**. 질량은 면적(r²)에 비례
- 프레임당 최대 8스텝까지만 따라잡아 스파이럴을 막습니다

**검증 기준**: 자동 플레이 후 원 겹침 최대치 0px, 통 밖으로 나간 개수 0.

## 5. 점수

```
합체 점수 = 단계별 기본값 × (1 + 연쇄 × 0.5)
```

| 단계 | 기본값 |
|---|---|
| 북거씨 | 1 |
| 할머니 | 3 |
| 람다 | 6 |
| 끼토 | 12 |
| 보늘 | 24 |
| 보늘 소멸 | 50 |

**연쇄**가 이 게임의 핵심 쾌감입니다. 합쳐진 것이 굴러가 또 합쳐지면 배수가 붙습니다. 0.55초 안에 이어지면 연쇄로 칩니다.

## 6. 메타 — 가볍게

방범대나 원정대처럼 무겁게 가지 않습니다. **판이 전부**라는 설계를 지킵니다.

| 요소 | 내용 |
|---|---|
| 최고 점수 | `somsom_merge_v1`에 저장, 타이틀과 HUD에 표시 |
| 제일 큰 친구 | 최고 도달 단계를 기록 |
| 도감 | 각 단계 **첫 도달** 시 허브 도감에 해금 |
| 도토리 | 점수 ÷ 10 을 허브 지갑에 적립 (다른 게임과 같은 지갑) |
| 업적 | 5종 |

업적

| id | 이름 | 조건 |
|---|---|---|
| `merge_first` | 첫 합체 | 한 번이라도 합쳤다 |
| `merge_kkito` | 끼토 등장 | 끼토까지 올렸다 |
| `merge_boneul` | 보늘 등장 | 보늘까지 올렸다 |
| `merge_chain4` | 네 번 연쇄 | 한 번에 4연쇄 |
| `merge_1000` | 천 점 | 한 판에 1000점 |

## 7. 랭킹 — 조용히

`docs/RANKING_SPEC.md` 규격을 따릅니다.

- 판이 끝나면 **버튼 없이** 올라갑니다
- 점수형 `merge_scores` = `{ n, s, t }`
- 진도형 `merge_progress` = `{ n, st:최고단계, b:최고점수, t }` (문서 ID = 닉네임)
- 실패해도 게임에 영향 없음 (`catch` 후 무시)

**Firestore 규칙에 `merge_scores`·`merge_progress`를 추가해야 실제로 올라갑니다.** 규칙 초안은 `docs/RANKING_SPEC.md`에 있습니다. 규칙 전에도 플레이에는 지장이 없습니다.

## 14. 리스크

**하나. 수박게임 클론으로 보일 수 있습니다.**
유명한 형태입니다. 다만 과일이 아니라 **캐릭터 여섯의 키 순서**를 씁니다. 미개 둘이 북거씨가 되고 끼토 둘이 보늘이 되는 건 이 IP에서만 나오는 규칙입니다. 껍데기가 아니라 설정이 규칙입니다.

**둘. 물리 튜닝.**
M0에서 안정성은 확인했지만(겹침 0, 이탈 0) 손맛은 실기에서 봐야 합니다. 반발과 마찰이 조금만 달라도 느낌이 크게 바뀝니다.

**셋. 삽화 559장을 안 씁니다.**
배경으로도 안 들어갑니다. 자산 활용이라는 관점에서는 세 안 중 가장 약합니다. 다만 콘텐츠 고갈이 없다는 점과 맞바꾼 결과입니다. 도감 해금으로 일부를 연결할 수 있습니다.

**넷. 또 안 할 수 있습니다.**
세 번째 시도입니다. 이번엔 M0를 먼저 통과했다는 점이 앞선 둘과 다릅니다.
