# GAME 05 (교체) 「당근빌라 창고 정리」 기획서 v0.1

> 한 줄 정의: 8×8 창고 선반에 주민들의 짐 상자를 끼워 넣고, 가로·세로 한 줄이 꽉 차면 정리되어 사라지는 블록 퍼즐.
> 남은 상자 세 개가 어디에도 안 들어가면 끝.

솜솜 합체를 대신합니다. 가을 바구니(GAME 06)와 같은 "떨어뜨려 합치기" 장르가 허브에 둘이라 겹쳤기 때문입니다.

## 1. 왜 이 장르인가

| 기준 | 판단 |
|---|---|
| 검증된 중독성 | 블록 블라스트 계열. 2025년 전 세계 다운로드 1위(3억 6,800만), 2026년 1분기에도 1위 |
| 허브와 안 겹침 | 반사신경(낙엽)·타이밍(달리기)·기억(짝맞추기)·전략(방범대)·물리 합치기(바구니)와 다른 **칸 퍼즐** |
| 진짜 실패가 있음 | 솜솜 합체의 약점(넘치지 않아 긴장이 없음)이 구조적으로 없다. 조각이 안 들어가는 순간이 곧 끝 |
| 가족 대결에 공정 | 손 빠르기가 필요 없다. 할머니와 아이가 같은 조건 |
| 폰 조작 | 조각을 끌어다 놓기 한 가지 |

## 2. 핵심 규칙

1. 아래에 상자 조각 3개가 나온다. 하나씩 끌어서 8×8 선반에 놓는다(회전 없음).
2. 가로나 세로 한 줄이 꽉 차면 그 줄이 정리되어 사라진다. 여러 줄을 한 번에 지우면 점수가 크게 뛴다.
3. 3개를 다 놓으면 새 3개가 나온다.
4. 남은 조각 중 어느 것도 놓을 자리가 없으면 끝.

## 3. 중독 장치

| # | 장치 | 내용 |
|---|---|---|
| 1 | 연속 정리 | 놓을 때마다 줄을 지우면 연속 +1, 점수 배수 상승. 3번 놓는 동안 한 줄도 못 지우면 끊김. 효과음이 단계마다 올라감 |
| 2 | 여러 줄 동시 | 2줄·3줄·4줄 동시 정리에 큰 보너스와 큰 연출 |
| 3 | 싹 비우기 | 선반을 완전히 비우면 대형 보너스 |
| 4 | 짐 주인 보너스 | 한 줄이 한 사람 짐으로만 채워져 정리되면 그 친구가 튀어나와 기뻐하고 ×2 |
| 5 | 아슬아슬 | 남은 자리가 적어지면 선반이 붉게 숨 쉬고, 놓을 곳 없는 조각은 흐리게 |
| 6 | 한 판 더 | 결과에 "최고까지 N점", "오늘 순위 바로 위 사람까지 N점", 게임 중 "최고보다 +/−" (솜솜 합체 v3.2에서 가져옴) |
| 7 | 매일 올 이유 | 오늘의 판: 날짜로 조각 순서가 정해져 모두 같은 문제. 날짜별 순위판 |

## 4. 솜솜 요소

- 상자는 6가지. 주민마다 한 가지 짐과 색(기존 삽화에 나온 물건만 씀):

  | 주민 | 짐 |
  |---|---|
  | 끼토 | 원고 뭉치 |
  | 미개 | 과자 봉지 |
  | 라칠친 할머니 | 실타래 |
  | 람다 | 단추 통 |
  | 보늘 | 카메라 |
  | 북거씨 | 향수병 |
- 줄이 정리되면 그 줄에 짐이 있던 주민들의 기뻐하는 얼굴(기존 `sd_*_win_t`)이 잠깐 떠오른다.
- 새 캐릭터·새 동물 없음. "창고 정리"는 캐논에 없는 사건(이사 등)을 만들지 않기 위한 설정이다.

## 5. 수치 목표 (자동 플레이로 맞춤)

- 한 판 4~8분, 평균 조각 60~120개
- 조각 생성은 무작위가 기본. 막히기 직전에 들어갈 조각이 나올 확률을 약간 올리는 도움 규칙은 봇으로 측정하고 넣을지 정한다
- 연속·여러 줄 보너스가 점수의 절반 이상이 되도록(실력 차가 점수에 드러나게)

## 6. 허브 연결 (기존 것 재사용)

솜솜시티 테마곡(`bgm.js`), 마을 창고(`village.js`), 오늘의 미션·업적·도감·주간 랭킹, 날짜별 순위판(Firestore 새 컬렉션 `boxes_scores` — 규칙 추가 필요).

## 7. 그림 (멀티샷 생성)

상자 6종 칸 그림, 선반 배경, 타이틀 그림. 캐논 체크: 끼토 코 없음, 미개 뒷다리 4 + 앞팔 2, 북거씨 네발·네모 검정 안경, 볼터치 없음.

## 8. 진행 순서

1. M0 코어: 선반·조각·끌어 놓기·줄 정리·끝 판정 → 봇으로 한 판 길이·점수 구조 측정
2. M1 손맛: 연출·효과음·그림
3. M2 연결: 허브·순위판·미션·업적
4. 허브 GAME 05 자리를 솜솜 합체에서 교체 (솜솜 합체 코드와 기록은 저장소에 남김)

## 9. 이번에 하지 않는 것

아이템·되살리기·도토리 상점, 조각 회전, 광고.
