# 신작 후보 「주민 원정」 시험판(M0)

작성 2026-10-14 · "캐릭터별로 점점 레벨업하는 재미" 요청 → A안(탕탕특공대식) 선택

## 한 줄
은행나무 골목에 골칫거리가 몰려옵니다. 주민은 움직이기만 하고 공격은 저절로. 3분 버티면 성공입니다.

## 레벨업이 두 겹
| | 판 안 레벨업 | 주민 레벨 (판 밖) |
|---|---|---|
| 무엇으로 | 골칫거리가 떨군 도토리 | 판이 끝나면 받는 경험치 (버틴 시간·물리친 수·성공·보스) |
| 얼마나 자주 | 첫 레벨업 약 7초, 한 판에 약 20번 | 1판 → Lv2, 약 3판 → Lv3, 약 6판 → Lv4, 약 10판 → Lv5 |
| 무엇이 열리나 | 기술 카드 3장 중 1장 (새 기술 / 단계 올리기 / 진화) | 새 기술 카드, 진화, 시작 기술 강화, 새 옷 |

교훈 반영: 골목 원정대(숫자만 바뀌는 동료)와 방범대 주민 강화(+8%)처럼 **숫자만 오르는 레벨업은 피함**. 주민 레벨이 오르면 판에서 고를 수 있는 기술 자체가 늘어남.

## 주민 (시험판은 둘)
| 주민 | 기본 | Lv2 | Lv3 | Lv4 | Lv5 |
|---|---|---|---|---|---|
| 람다 (빠름, 체력 낮음) | 도토리 던지기 · 꼬리 털기 | 단추 부메랑 | 불룩한 주머니 · 진화 「도토리 폭풍」 | 도토리 던지기 2단계로 시작 | 새 옷 · 체력 +15% |
| 북거씨 (느림, 단단함) | 향수 분무 · 바다향 파동 | 유칼립투스 장판 | 단단한 등딱지 · 진화 「밀물」 | 향수 분무 2단계로 시작 | 새 옷 · 체력 +15% |

공용 카드: 새 운동화(속도), 할머니 도시락(체력), 돋보기(범위), 모래시계(쿨타임).
진화: 기본 기술 5단계 + 짝 기술을 가지고 있으면 진화 카드가 맨 앞에 나옴.

## 골칫거리 (비주얼 바이블 §4: 화난 얼굴 없음, 흰 점 눈 + 옅은 볼)
먼지 뭉치, 굴러오는 은행(빠름), 꼬릿 구름(단단함), 젖은 낙엽 더미(아주 단단함), 2분 30초에 왕꼬릿 구름(보스, 6초마다 먼지 소환). 30초마다 포위 무리.

## 자동 플레이 측정 (`patrol/sim.js`, 사람 흉내 봇, 16판씩)
| 주민 레벨 | 람다 성공 / 보스 처치 | 북거씨 성공 / 보스 처치 |
|---|---|---|
| 1 | 약 65% / 거의 못 잡음 | 약 65~95% / 못 잡음 |
| 3 | 약 55% / 약 20% | 약 90% / 약 75% |
| 5 | 약 90% / 약 75% | 100% / 약 90% |
주민 레벨이 오를수록 보스를 잡게 됨 = 키운 보람이 보임. 사람 손맛은 실제 플레이로 다시 맞춤.

## 시험판에서 확인할 것
1. 판 안 레벨업이 신나는지 (카드 고르는 맛)
2. 주민 레벨이 오를 때 "다음 판이 기대되는지"
3. 3분이 적당한지, 너무 쉽거나 어려운지

## 시험용 기능
타이틀의 "레벨 올려 보기(시험)": 고른 주민의 레벨을 한 단계 올림. "처음부터": 주민 레벨 초기화.

## v2 (10/14) — 플레이 피드백: "카드 고르는 순간이 신나지 않음", "처음엔 살짝 어려움"
| 고친 것 | 내용 |
|---|---|
| 레벨업 순간 | 주민 둘레로 금빛 터짐 → 0.4초 뒤 카드 |
| 카드 | 기술마다 그림, 한 장씩 뒤집히며 등장(올라가는 소리), 새 기술은 파란 테두리·진화는 금빛+반짝임, 다 나온 뒤에만 눌림(실수 방지) |
| 고른 순간 | 고른 카드가 커졌다 주민 쪽으로 빨려 들어감, 그 기술 색 빛 + "도토리 폭풍!" 글자, 고른 기술이 바로 한 번 터짐, 잠깐 느린 화면 |
| 보물 상자 (새) | 40초마다 금빛 테두리 '반짝이는 골칫거리' 등장 → 잡으면 상자. 열면 흔들림 → 뚜껑 열림·빛 → 룰렛이 돌아 기술 1개(60%)·2개(30%)·3개(10%) 한꺼번에. 보스도 상자를 떨굼 |
| 난이도 | 부딪힘 피해가 처음엔 60%에서 2분 동안 100%로, 시작 골칫거리 수 줄임, 람다 체력 85→100 |

## v3 (10/14) — "스킬별로 눈에 보이는 효과" + 나머지 주민 4명
### 기술 효과
맞을 때 기술 색 불꽃과 숫자 색, 5단계는 금빛·큰 숫자. 기술마다 고유 연출(도토리·단추 잔상, 꼬리 휘두름+은행잎, 향수 안개, 물결·물방울, 장판 잎, 등딱지 육각 방패, 운동화 흙먼지 등).
