# 「할머니네 가을 바구니」 시니어 기획 검토 v1 (2026-09-27)

> 1차 빌드를 시니어 게임 기획자 관점에서 검토하고, 자동 플레이 봇으로 수치를 확인한 뒤 바로 고친 기록입니다.
> "느낌"이 아니라 측정값으로 판단한 항목은 표에 수치를 남겼습니다.

## 1. 총평

- **코어 재미는 성립합니다.** 합치기 물리가 안정적이고(열매 겹침 0.5% 이하, 정지 후 흔들림 없음), 한 판 4~6분으로 목표 범위 안입니다.
- **가장 큰 문제는 스킬이었습니다.** 한 판에 스킬이 8~14번 터져 게임 긴장감을 무너뜨렸고, 친구 6명 중 3명은 스킬이 점수에 거의 도움이 안 되거나 오히려 손해였습니다. 돈(도토리)을 내고 데려오는 친구가 기본 친구보다 약한 구조는 해금 동기를 망가뜨립니다.
- **첫 판 경험(FTUE)이 글 설명 화면으로 시작했습니다.** 캐주얼 게임에서 첫 화면에 6줄 설명을 읽히면 이탈합니다.
- **도토리 쓸 곳이 해금 4번뿐**이라 10판쯤 지나면 도토리가 의미 없어지는 구조였습니다.

## 2. 발견 사항과 조치

| # | 영역 | 발견 | 심각도 | 조치 |
|---|---|---|---|---|
| 1 | 밸런스 | 스킬 사용 횟수 한 판 8~14회 (목표 2~3회) | 높음 | 충전량 약 55% 축소 + **쓸 때마다 다음 충전 25% 느려짐** → 3~5회 |
| 2 | 밸런스 | 보늘 스킬(무게 증가+넘침 정지)이 점수 기여 -4% | 높음 | **뒹굴 청소**(맨 위 열매 3개 제거+2.5초 넘침 정지)로 교체 → +39% |
| 3 | 밸런스 | 람다 황금 도토리가 점수 -8~-15%. 원인: 열매를 키우기만 해서 바구니 부피가 늘어남 | 높음 | 닿은 열매의 **짝을 어디서든 끌어와 합치기**로 교체(부피 감소), 2개 지급 → +24% |
| 4 | 밸런스 | 북거씨(가장 비싼 친구) 스킬 -6~-12%. 같은 원인 | 높음 | 고른 열매와 **같은 열매 전부를 둘씩 짝지어 합치기**로 교체 → +17% |
| 5 | 버그 | 끼토 흔들기가 실제 시간 타이머로 동작 → 일시정지 중에도 흔들리고, 효과 측정 불가 | 중간 | 게임 시간 기준으로 재구현 |
| 6 | 밸런스 | 끼토 흔들기가 무작위라 효과 0%, 작은 열매가 바구니 위로 튀어나감 | 중간 | 흔들기 약하게 + **1.5초 동안 가까운 같은 열매끼리 끌어당김** 추가 → +19% |
| 7 | 밸런스 | 시작 친구인 할머니가 가장 강함(+41%) → 해금 동기 약화 | 중간 | 점수 2배 패시브 제거, 대신 "주운 열매당 도토리 +1" → +31% |
| 8 | FTUE | 첫 시작 시 6줄 설명 화면 | 높음 | 설명 화면 제거, 게임 안에서 단계별 안내 3개(끌어서 놓기 → 짝꿍 옆에 놓기 → 합쳐졌어요) |
| 9 | FTUE | 첫 합치기가 운에 달림 | 중간 | 처음 3판은 은행·은행·도토리·도토리로 시작 → 5초 안에 첫 합치기 |
| 10 | 가독성 | 들고 있는 열매의 짝이 어디 있는지 찾기 어려움(특히 사과·석류처럼 색이 비슷한 열매) | 중간 | 조준 중에 **같은 열매에 반짝이는 테두리** |
| 11 | 버그 | 막 떨어뜨린 열매 때문에 위험 표시(빨간 테두리·경고)가 판 시작부터 켜짐 | 중간 | 막 떨어진 열매는 위험 계산에서 제외 |
| 12 | 안내 | 스킬 버튼 존재를 모름 | 중간 | 첫 충전 시 "스킬 준비! 왼쪽 위 친구 얼굴을 눌러요" 안내 1회, 위험선 첫 접근 시 안내 1회 |
| 13 | 경제 | 해금 후 도토리 사용처 없음 | 중간 | **친구 레벨(Lv.1~5)**: 100/200/350/500, 레벨당 스킬 충전 +8% |
| 14 | 리텐션 | 결과 화면에 "다음 판을 할 이유"가 약함 | 중간 | **다음 목표 진행 막대**(다음 친구 해금 또는 레벨 업까지 도토리) |
| 15 | 화면 | 세로로 긴 폰에서 위아래 검은 띠 | 낮음 | 배경 그림으로 채움 |
| 16 | 화면 | 결과 화면이 넘쳐 아래 버튼이 잘림 | 중간 | 결과 카드 압축 |
| 17 | 접근성 | 화면 흔들림 끄기 없음 | 낮음 | 기기에서 '동작 줄이기'를 켜면 흔들림 없음 |

- 목표: 모든 친구가 "스킬 없이"보다 확실히 낫고(+15% 이상), 한 명이 압도적이지 않게(+40% 이하).
