# 캐주얼 게임 장르 조사 — GAME 06 재기획용

작성 2026-09-13 · 「골목 원정대」 탈락, 「틀린그림찾기」 기각 후

---

## 0. 왜 조사했나

두 번 실패했습니다.

| 안 | 왜 접었나 |
|---|---|
| 골목 원정대 (피한다) | 만들어 보니 낙엽피하기와 구분이 안 됨. **동사를 안 바꿔서** |
| 틀린그림찾기 (찾는다) | 한 번 푼 그림은 끝. **콘텐츠가 고갈되고 외워짐** |

그래서 기준이 하나 늘었습니다.

> **절차적으로 무한해야 합니다.** 콘텐츠를 사람이 만들어 채우는 구조면 곧 바닥납니다.

이게 방범대와 낙엽피하기가 오래 가는 이유이기도 합니다. 웨이브와 낙엽은 매번 새로 생성됩니다.

---

## 1. 시장이 뭘 하고 있나

2026년 상반기 캐주얼 시장 기준입니다.

| 장르 | 위치 |
|---|---|
| **퍼즐** | 캐주얼 매출의 **44% 이상**. 최대 장르 |
| └ 매치-3 | IAP 25억 달러, 다운로드 3.92억 |
| **머지(Merge)** | **2위, 가장 빠르게 성장.** IAP 13억 달러, 다운로드 3.11억 |
| 시뮬레이션 | 요리·공방 운영 등 |
| 방치형(Idle) | 장르가 성숙기 |

머지가 "새로운 매치-3"로 불리며 올라오는 중이고, 하이퍼캐주얼은 **하이브리드캐주얼**(단순 조작 + 가벼운 메타 성장)로 대체되는 흐름입니다.

## 3. 우리 조건에 대입

기준 일곱 개로 걸렀습니다.

| | 한 판 5분 | 그 자리 완결 | **새 동사** | **무한** | 아이/어른 대등 | 신규 작화 | 삽화 활용 |
|---|---|---|---|---|---|---|---|
| 매치-3 | ✓ | ✓ | 애매 | ✓ | ✓ | 중 | 약함 |
| **드롭&머지** | ✓ | ✓ | **✓** | **✓** | **✓** | **최소** | 중간 |
| 머지-2 보드 | ✓ | ✓ | ✓ | ✓ | ✓ | 중 | 중간 |
| 소팅 퍼즐 | ✓ | ✓ | ✓ | ✓ | ✓ | 소 | **약함** |
| 스태킹 | ✓ | ✓ | 애매 | ✓ | 반사신경 | 소 | 약함 |
| 방치형 | ✗ | ✗ | ✓ | ✓ | ✓ | 중 | 중간 |
| 시뮬레이션 | ✗ | 애매 | ✓ | 중간 | ✓ | 대 | 중간 |

탈락 사유

- **매치-3** — 짝맞추기(GAME 03)와 화면이 비슷해 보입니다. 또 겹칩니다
- **스태킹** — 결국 타이밍 반사신경. 낙엽피하기·달리기와 결이 같습니다
- **방치형** — 판이 그 자리에서 안 끝납니다. 「끼토의 하루」가 실패한 바로 그 지점
- **시뮬레이션** — 한 판이 깁니다. 제작비도 큽니다
- **소팅 퍼즐** — 조건은 다 통과하는데 **캐릭터가 안 나옵니다.** 색깔 정렬에 솜솜시티를 붙일 방법이 마땅치 않습니다

## 4. 추천: 드롭 & 머지

수박게임(Suika Game)으로 알려진 형태입니다. 통에 물건을 떨어뜨리고, 같은 것끼리 닿으면 한 단계 큰 것으로 합쳐집니다. 넘치면 끝.

### 왜 이게 맞나 — 결정적인 이유

**솜솜시티는 이미 크기 사다리를 갖고 있습니다.**

비주얼 바이블에 확정된 캐릭터 키 순서입니다.

```
미개 37  →  북거씨 43  →  라칠친 52  →  람다 61  →  끼토 91  →  보늘 100
```

머지 게임이 필요로 하는 게 **정확히 이겁니다.** 여섯 단계 사다리.

```
미개 + 미개   →  북거씨
북거씨 + 북거씨 →  할머니
할머니 + 할머니 →  람다
람다 + 람다    →  끼토
끼토 + 끼토    →  보늘        ← 최종
```

억지로 갖다 붙인 게 아닙니다. **원화가 정한 키 순서가 그대로 게임 규칙이 됩니다.** 캐릭터를 여섯만 쓴다는 제약이 오히려 딱 맞는 단계 수입니다.

### 나머지 기준도 통과합니다

| 기준 | |
|---|---|
| 한 판 | 2~4분 |
| 그 자리 완결 | 넘치면 끝, 점수가 남음 |
| 새 동사 | **떨어뜨린다 · 합친다.** 피한다/뛴다/기억한다/배치한다 어디와도 안 겹침 |
| 무한 | 물리 + 랜덤 순서라 같은 판이 없음. **사람이 콘텐츠를 만들 필요가 없음** |
| 아이/어른 | 반사신경이 아니라 자리 잡기. 대등 |
| 신규 작화 | **0~6장.** 기존 스프라이트를 원 안에 넣으면 됩니다 |

### 재미의 원리 (조사에서)

- **연쇄(체인)** — 합쳐진 게 굴러가서 또 합쳐지고, 또 합쳐집니다. 이 연쇄가 도파민의 핵심입니다
- **예측 불가능한 물리** — 튀고 구르고 밀립니다. 그래서 같은 판이 안 나옵니다
- **시간 압박이 없습니다** — 침착하게 생각할 수 있어 아이도 어른도 됩니다. 대신 통이 차오르는 긴장이 있습니다

### 위험

**하나. 수박게임 클론으로 보일 수 있습니다.**
유명한 형태입니다. 다만 우리는 과일이 아니라 **캐릭터 여섯의 키 순서**를 씁니다. 미개 둘이 북거씨가 되고 끼토 둘이 보늘이 되는 건 이 IP에서만 나오는 규칙입니다. 껍데기가 아니라 설정이 규칙이 됩니다.

**둘. 물리 엔진이 필요합니다.**
원형 강체 충돌만 있으면 됩니다. 외부 라이브러리 없이 200줄 정도로 직접 짤 수 있습니다. 위험은 낮지만 튜닝에 시간이 듭니다.

**셋. 삽화 559장을 직접 쓰진 않습니다.**
배경과 연출, 해금 보상으로만 들어갑니다. 틀린그림찾기만큼 자산을 쓰지는 못합니다. 다만 그 안은 콘텐츠 고갈 때문에 접었습니다.

### M0 (반나절)

물리와 합체만 만들고 **원 여섯 개를 색깔로만** 그립니다. 그림 없이 재미있는지 봅니다. 재미없으면 거기서 멈춥니다. 캐릭터를 입히는 건 그다음입니다.

---

## 5. 차선: 머지-2 보드

물리 없이 격자 위에서 드래그해 합칩니다. 물리 튜닝 위험이 없고 더 차분합니다. 대신 연쇄의 쾌감이 약하고, 제작비는 조금 더 듭니다(격자 UI·아이템 아이콘).

드롭&머지의 M0에서 물리가 안 잡히면 여기로 내려오면 됩니다.
