# 보관한 게임

허브(마을)에서 내린 게임입니다. 파일은 그대로 두어 언제든 다시 꺼낼 수 있습니다.
옛 주소(`/match/` 등)로 들어오면 "쉬는 중" 안내 뒤 허브로 이동합니다.
순위(Firestore)·도감·업적 기록은 지우지 않았습니다.

| 폴더 | 게임 | 내린 이유 |
|---|---|---|
| `match/` | 짝맞추기 | GAME 03 자리를 주민 원정이 이어받음 |
| `merge/` | 솜솜 합체 | GAME 05 자리를 창고 정리가 이어받음 |
| `expedition/` | 골목 원정대 | 허브에서 빠진 뒤 기록 거의 없음 |
| `day/` | 끼토의 하루 | 포스트모템(`docs/POSTMORTEM_kkito_day.md`) 참고 |

다시 꺼낼 때: 폴더를 루트로 옮기고 `../../` 경로를 `../`로 되돌린 뒤, 허브 `index.html`에 칸을 추가합니다.
허브는 여섯 칸 고정 — 하나를 올리면 하나를 내립니다 (노션 「솜솜시티 게임 PO 정리」 1장 규칙).
