# 솜솜 UI — 새 게임을 마을에 올릴 때 체크리스트

놀이판은 게임마다 달라도 **판 밖(위 바·버튼·시트·결과·용어)은 여섯 게임이 같다.**
기획: 노션 「솜솜시티 게임 PO 정리 — 포트폴리오 + UI/UX 통일 (2026-11)」 3장 · 그림: 「게임 그림 점검 리스트」

## 1. 불러오기

- `<head>` 맨 끝에 `<link rel="stylesheet" href="../ui/somsom-ui.css">`
  - 다른 저장소의 게임은 주소로 불러온다: `https://pang861209-rgb.github.io/somsom-city/ui/somsom-ui.css`
- 마을 창고는 `village.js`, 노래 버튼은 `assets/bgm.js`
- 본문 글꼴은 `'Gowun Dodum'`, 제목 글꼴은 `'Black Han Sans'`

## 2. 버튼 이름표

| 이름표 | 쓰는 곳 | 규칙 |
| --- | --- | --- |
| `.sui-cta` | 시작 "(동사)하러 가기", 결과 "한 판 더", 일시정지 "이어하기" | 주황. **한 화면에 하나** |
| `.sui-pill` | 보조 버튼 (방법·도감·기록·순위·주민 바꾸기·처음으로·닫기) | 반투명 알약 40px |
| `.sui-pill.sui-hot` | "오늘의 도전"처럼 하나만 눈에 띄어야 하는 보조 버튼 | 은행 노랑 |
| `.sui-pill.sui-sm` | 좁은 줄에 여럿 나란히 | 34px |
| `.sui-pill.sui-paper` | 밝은 종이 카드·시트 위 알약 | |
| `.sui-chip` (+ `.on`) | 기간(오늘·이번 주·전체), 챕터, 필터 | 30px 알약, 고른 것은 노랑. 밝은 바탕은 `.sui-paper` 함께 |
| `.sui-icon` | 일시정지 `❙❙` | 36px |
| `.homeBtn` | `← 홈` | 첫 화면 왼쪽 위 |

보이기·숨기기는 게임이 정한다. `.hidden`이나 `display:none`을 쓰면 된다. 공통 UI는 display를 명시도 0으로만 깔아 둔다.

## 3. 화면 틀

- **첫 화면:** 큰 삽화 + 제목 + 부제 알약 + 주황 시작 버튼 + 보조 버튼 줄 + `GAME 0N · 이름`
  - 보조 버튼 순서는 **방법 · 도감 · 기록 · 순위**
- **일시정지:** 제목 "잠깐 쉬는 중" · 주황 "이어하기" · 알약 "그만하기" (필요하면 "처음부터")
- **결과:**
  - 점수를 보여 준다
  - 신기록이면 "🎉 신기록!"
  - 최고 기록과 20% 안이면 "아깝다! 신기록까지 N점", 아니면 "최고 기록 N점"
  - 그 아래 주황 "한 판 더" 한 줄, 그 아래 알약 (순위 · 주민 바꾸기 · 처음으로)
- **모서리:** 작은 것 12 · 누르는 카드와 버튼 16 · 시트와 패널 22 · 칩은 알약
- **메뉴 바탕:** 메뉴·로비·결과·시트는 밤 바탕 `#221E18`. 놀이판은 자유
- **알림:** 업적 알림은 `#achToast` + `.on`. 마을 창고 알림이 그 아래에 저절로 선다

## 4. 용어 사전

| 기능 | 쓸 말 | 안 쓸 말 |
| --- | --- | --- |
| 점수 순서 | 순위 | 랭킹 |
| 놀이 설명 | 방법 | 도움말, 기술 보기 |
| 허브로 | ← 홈 | 🏘 마을로, ← 타이틀로 |
| 한 화면 뒤로 | ← 뒤로 | (화면을 닫는) 닫기 |
| 다시 하기 | 한 판 더 | 다시 도전, 재시작 |
| 시작 | (동사)하러 가기 | 시작하기 |
| 캐릭터 | 주민 (주민 고르기 · 주민 바꾸기) | 캐릭터 선택·변경 |

시트(창)의 "닫기"는 그대로 쓴다. 바깥을 누르면 닫힌다는 걸 모르는 사람을 위해서다.

## 5. 마을 연결

- 한 판이 끝나면 `SV.add('게임id', 도토리, 주민)`를 부른다. 게임 id는 `village.js`의 GAMES에 추가한다
- 이름은 `localStorage.somsom_name` 하나를 모든 게임이 같이 쓴다
- 허브는 **여섯 칸 고정**이다. 새 게임은 기존 하나를 내릴 때만 올린다
  - 내리는 기준: 4주 연속 주 3판 미만 + 업데이트 계획 없음

## 6. 그림

- 노션 「솜솜시티 그림체 가이드 v2」를 따른다. 원화를 참조로 넣고 짧게 지시하며, 멀티샷으로 묶어 만든다
- **끼토는 코가 없다.** 입선 위에는 아무것도 없고, 입선 밑에 짧은 선이 하나 있다. 이마 잔머리는 "ss"
- 보늘은 크림·세이지 줄무늬 티, 람다는 앞니 없음, 북거씨는 네모난 검은 안경에 네 발
- 크기는 폰 화면(배율 3배)에서 그려지는 크기의 1~1.5배로 한다. 너무 작으면 흐리고, 너무 크면 로딩이 느리다

## 7. 확인

- 휴대폰 390×844에서 첫 화면 → 시작 → 일시정지 → 결과 → 한 판 더 → ← 홈까지 오류 0
- 낮은 화면에서 위가 잘리지 않는지 본다 (가로 340px, 아이폰 SE 크기)
- 주황 버튼이 화면마다 하나인지 본다
